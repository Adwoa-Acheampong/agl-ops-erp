# AGL Ops — Operations Command Center

Operations & workshop management platform for Automobiles Ghana Limited. Standalone build — no longer tracked as a GitHub repository.

## Stack

- **Front-end**: React 18 + Vite + Tailwind CSS + shadcn/ui + lucide-react
- **Back-end**: Express + tRPC + Drizzle ORM (MySQL)
- **AI**: Anthropic Claude (FixBot assistant)
- **Data ingestion**: SheetJS (xlsx) for Excel imports

## Quick start

```bash
npm install                 # install dependencies
cp .env.example .env        # configure DATABASE_URL, ANTHROPIC_API_KEY, etc.
npm run dev                 # http://localhost:3000
```

The Express server hosts Vite in middleware mode on `PORT` (default 3000). The dev script is `tsx watch server/_core/index.ts`.

## Project layout

```
src/                React UI — pages, components, contexts, lib (tRPC client)
server/             Express + tRPC routers, DB layer, OAuth, scheduler
drizzle/            Schema, relations, migrations, snapshots
shared/             Code shared between client and server
patches/            npm patches (patch-package)
public/             Static assets served at site root
  brand/sedan-red.jpg|png   Hero illustration on /login and /welcome
  agl-logo.jpeg             Favicon
```

## Configuration files

| File | Purpose |
|---|---|
| `package.json` | scripts + deps |
| `vite.config.ts` | Vite + path aliases (`@/...` → `./src/...`) |
| `tailwind.config.js` | Brand red palette, radius scale, font-family tokens |
| `tsconfig.json` | TypeScript config |
| `drizzle.config.ts` | Drizzle migration generator |
| `.env` | DB connection, API keys (NOT committed) |
| `.env.example` | template for `.env` |

## What was intentionally excluded from the transfer

- `.git/` — this build is no longer a GitHub repo
- `.github/` — CI workflows for the old repo
- `node_modules/` — reinstall with `npm install`
- `dist/` — build output, regenerated by `npm run build`
- `pnpm-lock.yaml` — superseded by `package-lock.json`
- `netlify.toml`, `vite.config.ts.bak` — orphaned configs
